# ☕ Java Core Course

Projeto desenvolvido em **Java** com o objetivo de praticar os principais conceitos da linguagem, desde fundamentos até Programação Orientada a Objetos (POO).

Este repositório reúne exercícios e exemplos práticos criados durante os estudos, abordando variáveis, estruturas de controle, orientação a objetos e boas práticas de programação.

---

## 📖 Sobre o projeto

O objetivo deste projeto é consolidar os conhecimentos fundamentais da linguagem Java por meio de exemplos simples e organizados em pacotes temáticos.

Durante o desenvolvimento foram praticados conceitos essenciais para a construção de aplicações Java.

---

## 🚀 Conteúdo do projeto

### 📌 Variables

Exemplos relacionados aos conceitos básicos da linguagem.

- Declaração de variáveis
- Tipos primitivos
- Conversão de tipos (Casting)
- Impressão de valores

Arquivos:

- `HelloVariables.java`
- `TypeCasting.java`

---

### 🔀 Controlflow

Exemplos de estruturas de decisão e repetição.

- if / else
- for
- while

Arquivos:

- `IfElseExample.java`
- `ForLoopExample.java`
- `WhileExample.java`

---

### 🧩 Object-Oriented Programming (OOP)

Exemplos utilizando Programação Orientada a Objetos.

Conceitos abordados:

- Classes
- Objetos
- Atributos
- Métodos
- Encapsulamento
- Instanciação de objetos

Arquivos:

- `Person.java`
- `Car.java`
- `Account.java`
- `Main.java`

---

### 🎨 Util

Classe utilitária utilizada para melhorar a saída no console.

Arquivo:

- `ConsoleColors.java`
